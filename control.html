Ailovanta Coding

Your GPU. Your code. One serious coding model.

Ailovanta runs coding inference on your own computer by default. Private project files and prompts stay on that computer. The public server coordinates versions and opt-in public compute; it does not need to run your coding model.

No model API requiredPrivate-local by defaultFrontend + Backend + RepairCommunity compute is opt-in

macOS / Linux

Clone once, then Ailovanta detects your hardware, starts local Ollama if available, chooses a model profile, and opens the private workspace.

git clone https://github.com/ZqiEE/ailovanta.git
cd ailovanta
bash start-local.sh

Windows PowerShell

The same local path works on Windows. The first run may download the selected open bootstrap model to your own machine.

git clone https://github.com/ZqiEE/ailovanta.git
cd ailovanta
.\start-local.ps1

Contribute idle compute

Optional. Community mode accepts public or synthetic workloads only and has CPU/GPU/temperature limits. Private project inference is rejected by worker policy.

python -m node_client.client_real --api-url https://YOUR_DOMAIN --contribution 30
Bootstrap models are temporary. The product architecture is designed so Ailovanta's own unified distilled checkpoint can replace them without changing the local workflow.
